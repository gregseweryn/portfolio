## Priority Issues

### [P0] The proof is placeholder — the portfolio proves nothing yet
studies.ts is explicitly placeholder; email is TODO; LinkedIn/Medium links point at homepages; every visual is a MediaFrame placeholder. Fabricated metrics on invented studies is a credibility risk. Fix: replace with real studies + real links before launch; shell swaps content with zero layout change. Command: /impeccable harden

### [P0] Live-mode dev script committed into production layout
layout.tsx:71-73 ships <script src="http://localhost:8400/live.js"> on every page — guaranteed failed localhost request in production. Fix: delete the three impeccable-live lines. Command: /impeccable harden

### [P1] Zero real imagery on a portfolio that implies artifacts
Every image slot is a grey "Artifact placeholder." Reads as a template awaiting content; undercuts "show, don't tell." Fix: ship real artifacts (redacted/NDA framing is itself a signal). Command: /impeccable harden

### [P2] Four simultaneous motion systems risk chrome out-shouting the work
Custom cursor + film grain (0.4 opacity) + dual WebGL shaders + Lenis + SplitText + magnetic buttons + scroll reveals. North star is "quiet structure that lets loud type speak." Fix: keep 2 moves (SplitText + hero shader), cut/dial back the rest; test grain at 0.2 or drop; question cursor:none. Command: /impeccable quieter

### [P2] Two near-identical email CTAs stack back-to-back
Home contact band + Footer both use the same CopyEmail CTA consecutively. Fix: differentiate — one climax, one fine print. Command: /impeccable layout
